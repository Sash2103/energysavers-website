# Energy Savers website

Proposed redesign of energysavers.me: the homepage, every inner page and the blog.
It is built with Next.js (App Router) as a static export: `npm run build` writes plain HTML, CSS and JS to `out/`, which any static host can serve. There is no server, no API and no database.
The inner pages are built from the old site's content (`content/`) when the site is built.
It is a private preview, so every page carries `noindex`. Don't publish it or point a domain at it until the owner approves.

## Run locally

Needs Node.js 20.9 or later.

```sh
npm install
npm run dev        # then open http://localhost:3000
```

Inner pages keep the old site's addresses, for example http://localhost:3000/ahf/, /hospitality/ or /blog/.
Add `?motion=off` to any URL to see the reduced-motion version.
The dev server only listens on this computer (localhost), not on the network.

## Build

```sh
npm run build      # writes the whole site to out/
```

`out/` holds one folder per page (`out/ahf/index.html`, …), the images and fonts in `out/assets/`, and Next's scripts in `out/_next/`.
To look at the build itself, serve the folder, for example `python3 -m http.server 8080 --bind 127.0.0.1 --directory out`, then open http://localhost:8080.

## Deploy to Cloudflare Pages

Only when the owner has approved the redesign.

1. Push the repository to GitHub, then in Cloudflare: Workers & Pages → Create → Pages → Connect to Git, and pick the repository.
2. Framework preset: None. Build command: `npm run build`. Build output directory: `out`.
3. Environment variables: none are needed. If the build picks an old Node version, set `NODE_VERSION` to `20` or later.

Every push to the branch then rebuilds the site. The pages use root-relative addresses (`/assets/…`), so serve the site from the root of a domain or subdomain (a `*.pages.dev` address, or a GitHub Pages user or custom domain), not from a sub-folder.

## Files

| Path | What it is |
|---|---|
| `app/layout.jsx` | Every page's `<head>` (`noindex`, icons, font preloads, the before-paint motion/loader script), the icon sprite and the loader |
| `app/page.jsx` | The homepage: its sections, plus the product sheet, case sheet and certificate viewer |
| `app/[slug]/page.jsx` | All 117 inner pages and blog posts, one static page per address |
| `app/globals.css` | Design tokens, components, sections, motion (the old `styles.css`, unchanged apart from the font paths) |
| `components/site/` | Header, Footer, Contact (with the enquiry form), quick call buttons, logo, sprite, loader, and the `Shell` that puts them around a page |
| `components/home/` | Homepage sections: Hero, Proof (Stats and CaseStudies), ActiveHarmonicFilter, HeatPump, Products, Offer (Solutions and Services), Sectors, About, Insights, and the sheets |
| `components/shared/` | Parts used on the homepage and inner pages: case write-up and workplan, product lines, service cards, About parts, post links, icons |
| `components/inner/` | Building blocks of the inner pages: page head, bands, tiles, prose |
| `components/behaviour/` | Small client components that add behaviour (the old `script.js`, one file per job): menus, hero waveform, exploded drawings, workplans, sheets, rail, sector photos, tabs, contact form, quick buttons, logo |
| `components/drawings/` | The exploded AHF and heat pump drawings, generated by the tools below. Don't edit them by hand |
| `data/cases.js`, `data/sectors.js` | The case studies and sectors, shared by the homepage, the case and sector pages and the lists |
| `lib/pages.jsx` | Lays out every inner page and post from `content/` (it replaces the old `tools/build-pages.py`) |
| `lib/site.js` | Site map, menu labels and the owner notes for single pages |
| `content/` | The old site's text, saved as JSON by `tools/scrape-pages.py` (pages and blog posts), and `images.json`, the inner-page image sizes written by `tools/build-images.py` |
| `public/assets/fonts/` | Archivo and Source Serif 4 (roman, and italic for the last word of headings), trimmed; OFL licences alongside |
| `public/assets/img/` | Homepage WebP images from energysavers.me, plus a few free Pexels photos where the old site's copies were too small (listed in NOTES.md), resized by `tools/fetch-assets.py` |
| `public/assets/img/up/` | The inner pages' images from the old site, re-encoded to WebP by `tools/build-images.py` |
| `public/assets/svg/` | Logo (vector trace of the original) and favicon |
| `tools/` | Dev-only scripts, see below |
| `PROJECT_DESIGN.md` | Design brief: palette, type, components, motion rules |
| `NOTES.md` | What the owner must confirm, content changes, checks run, blacklist audit |

Everything in `public/` is served as it is, at the same path without `public` (`public/assets/img/x.webp` is `/assets/img/x.webp`).

## Tools

```sh
python3 tools/fetch-assets.py    # re-download and re-encode the homepage images (needs Pillow)
python3 tools/scrape-pages.py    # save the old site's pages and posts into content/ (raw HTML cached in tools/.cache/)
python3 tools/build-images.py    # measure the inner pages' images into content/images.json (needs Pillow);
                                 #   add --encode to write any missing WebP files into public/assets/img/up/
node tools/draw-ahf.mjs          # regenerate the exploded AHF drawing (components/drawings/AhfDrawing.jsx)
node tools/draw-heat-pump.mjs    # regenerate the exploded heat pump drawing (components/drawings/HeatPumpDrawing.jsx)
node tools/contrast-check.mjs    # WCAG AA contrast audit of the palette
sh tools/build-fonts.sh          # rebuild the trimmed fonts into public/assets/fonts (needs fonttools + brotli)
npx html-validate "out/**/index.html"   # HTML checks for every built page (run npm run build first; config in .htmlvalidate.json)
```

If the content gains a new image, the build stops and prints the `tools/build-images.py --encode …` command to run.
The header, contact section and footer are components, so a change to them reaches every page on the next build.

## Secrets

None are used, and no `.env` file is needed. The contact form opens the visitor's email app or WhatsApp with the message filled in; nothing is sent to a server.
