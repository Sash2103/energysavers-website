# Energy Savers website

Proposed redesign of energysavers.me: the homepage, every inner page and the blog, as a static site.
The pages are plain HTML, so there is nothing to build before viewing them. The inner pages are generated from the old site's content by a script (see Tools).
It is a private preview, so every page carries `noindex`. Don't publish it or point a domain at it until the owner approves.

## Preview

```sh
python3 -m http.server 8080      # then open http://localhost:8080
```

Inner pages keep the old site's addresses, for example http://localhost:8080/ahf/, /hospitality/ or /blog/.
Add `?motion=off` to any URL to see the reduced-motion version.

## Files

| Path | What it is |
|---|---|
| `index.html` | The homepage, including the quick-view product and case-study sheets and the inlined AHF and heat pump drawings. Its header, contact section and footer are reused by every other page |
| `<slug>/index.html` | Inner pages, the blog list and blog posts (117 folders), generated by `tools/build-pages.py`. Don't edit them by hand |
| `content/` | The old site's text, saved as JSON by `tools/scrape-pages.py` (pages and blog posts) |
| `styles.css` | Design tokens, components, sections, motion |
| `script.js` | Menus, hero waveform, exploded AHF and heat pump drawings, sheets, workplans, services rail, sector tabs, contact form (one file for every page) |
| `assets/fonts/` | Archivo and Source Serif 4 (roman, and italic for the last word of headings), trimmed; OFL licences alongside |
| `assets/img/` | Homepage WebP images from energysavers.me, plus a few free Pexels photos where the old site's copies were too small (listed in NOTES.md), resized by `tools/fetch-assets.py` |
| `assets/img/up/` | The inner pages' images from the old site, re-encoded to WebP by `tools/build-pages.py` |
| `assets/svg/` | Logo (vector trace of the original) and favicon |
| `tools/` | Dev-only scripts, see below |
| `PROJECT_DESIGN.md` | Design brief: palette, type, components, motion rules |
| `NOTES.md` | What the owner must confirm, content changes, checks run, blacklist audit |

## Tools

```sh
python3 tools/fetch-assets.py   # re-download and re-encode the homepage images (needs Pillow)
python3 tools/scrape-pages.py   # save the old site's pages and posts into content/ (raw HTML cached in tools/.cache/)
python3 tools/build-pages.py    # regenerate every inner page and post from content/ and index.html (needs Pillow)
node tools/draw-ahf.mjs         # regenerate the exploded AHF drawing inside index.html
node tools/draw-heat-pump.mjs   # regenerate the exploded heat pump drawing inside index.html
node tools/contrast-check.mjs   # WCAG AA contrast audit of the palette
sh tools/build-fonts.sh         # rebuild the trimmed fonts (needs fonttools + brotli)
npx html-validate index.html */index.html   # HTML checks for every page (config in .htmlvalidate.json)
```

After editing the homepage's header, contact section or footer, run `tools/build-pages.py` so every page picks up the change.

## Secrets

None are used. The contact form opens the visitor's email app or WhatsApp with the message filled in; nothing is sent to a server.
